# uorc: the Prism's objects as uorc archives

Every value the vault keeps is its uorc archive (UOR-Foundation/compression),
named by the kappa label of the bytes it restores. `objects.mjs` compresses,
reads the archive's structure without decoding, restores within the client's
work bound, and asks the proved facets kappa and uorc; the vault seals what
they keep (`openVault({ objects })`).

| File | Holds |
| --- | --- |
| `objects.mjs` | `loadClient()`, `makeObjects({ client, decide, halted })`, `structureOf`, `rootDecide(dispatch)` |
| `uorc.lock.json` | the pinned release asset, the files it serves and the standard basis its archives name |
| `client/` | written by `bootstrap/uorc-objects.mjs` in pages.yml, never committed |
| `table.mjs` | generated by `tools/uorc/gen.py`: the facet's tree, the guest's mirror |
| `guest.mjs`, `guest/uorc.wasm` | the standalone guest, built by `tools/uorc/standalone.py`, pinned by SHA-256 |
| `uorc.test.mjs` | UO-01: all 576 requests against the guest, the mirror and the 14 guarantees |

`test/uorc/objects.test.mjs` (UO-02, UO-03) runs the pinned client, both
guests and the real vault in Node; pages.yml runs it after serving the client.

## Planted defects

| Defect | Gate | Diagnostic |
| --- | --- | --- |
| request fields out of the adapter's order (halted last) | `node test/uorc/objects.test.mjs` | `a sound object is kept: keep no ok known standard one same admit` (the guest answered invalid) |
| client bytes with one flipped bit | `node test/uorc/objects.test.mjs` | `loadClient` rejects with code `uorc.client` |
| a flipped seal bit, an archive of other bytes, several objects, another basis, halted | `node test/uorc/objects.test.mjs` | each answers refuse |
| a facet that answers keep to an open | `node test/uorc/objects.test.mjs` | `an open is projected only on the answer open` |
| a vault opened without the objects | `node test/uorc/objects.test.mjs` | `a vault without the objects never opens an archive record` |
