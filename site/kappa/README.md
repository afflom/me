# kappa: kappa labels in the browser

The Prism's content address from UOR-Foundation/kappa-registry
(`feat/rewrite-after-poc`, commit `618f477745e601f1bf1bd5cc62aed6fea4c8936d`):
`<axis>:<lowercase hex digest>`. The proved facet `PrismKappa`
(`app/specs/kappa/`) reads the label and decides; `kappa.mjs` re-derives the
digest with WebCrypto on the axes the spec gives a host algorithm (SHA-256,
SHA-512) and says match, mismatch or uncomputed.

| File | Holds |
| --- | --- |
| `kappa.mjs` | `labelOf(bytes, axis)`, `makeKappa({ decide }).admit(label, bytes)`, `rootDecide(dispatch)` |
| `table.mjs` | generated by `tools/kappa/gen.py`: the axes, the reader and the tree, the guest's mirror |
| `guest.mjs`, `guest/kappa.wasm` | the standalone guest, built by `tools/kappa/standalone.py`, pinned by SHA-256 |
| `kappa.test.mjs` | KP-01 and KP-02 in Node: every label shape on every axis against the guest, the mirror and the eight guarantees |

    node site/kappa/kappa.test.mjs
